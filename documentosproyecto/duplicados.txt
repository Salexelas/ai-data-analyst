🚨 Problema

Inconsistencias futuras aseguradas
✅ SOLUCIÓN

Crear:

class DuckDBBaseConnector(BaseConnector):
    def __init__(self, df):
        self.conn = duckdb.connect()
        self.conn.register("data", df)

    def execute(self, query):
        return self.conn.execute(query).df()

    def get_schema(self):
        return self.conn.execute("DESCRIBE data").df()

    def preview(self, limit=10):
        return self.conn.execute(f"SELECT * FROM data LIMIT {limit}").df()

Y después:
