Notas del diagrama
main.py → UI pura, no lógica.
helpers.py → funciones de soporte (validación, creación de config, llamada a factory).
factory.py → Registry + Factory: mapea source_type → ConnectorClass.
BaseConnector → define execute, get_schema, preview → Template Method.
Conectores concretos → heredan de BaseConnector, implementan execute() o detalles específicos.
Agents/Core → SQL Agent y LLM llaman al conector para ejecutar queries y devolver resultados.
config.yaml → mantiene URIs, paths, base_urls, y permite inputs dinámicos desde UI.
